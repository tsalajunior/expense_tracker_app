La commande `python manage.py shell` lance une console interactive Python qui charge tout l'environnement de votre projet. Elle permet de tester du code en direct, d'interagir avec la base de données et d'utiliser vos modèles Django sans lancer le serveur web. [[1](https://python.plainenglish.io/exploring-vs-code-python-and-the-python-manage-py-shell-command-3ac20b13e7cb), [2](https://englishforengineers.jimdofree.com/2025/05/04/django-python-manage-py-shell/), [3](https://www.youtube.com/watch?v=jvhFevP1TrA&t=200)]

**Utilité principale**

* **Tester des requêtes :** Interroger la base de données via l'ORM de Django (ex: `MonModele.objects.all()`).
* **Modifier des données :** Créer, modifier ou supprimer des objets directement.
* **Déboguer :** Vérifier rapidement si une fonction ou un module fonctionne comme prévu dans le contexte du projet.
